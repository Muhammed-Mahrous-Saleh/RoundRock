# ♻️ Round Rock – Trash Hauling Landing Page

**Round Rock** is a sample project that demonstrates the transformation of a **Figma design** into a fully responsive and visually polished web landing page. It simulates a trash hauling company's online presence, showcasing modern frontend practices and design-to-code implementation.

---

## 🎯 Project Purpose

This project was created to practice and demonstrate:

-   Turning a static **Figma UI design** into a dynamic, production-ready website
-   Applying **responsive design** principles across screen sizes
-   Building modular and clean React components
-   Utilizing **custom SVGs** and utility-first CSS for scalable visuals

---

## 🛠️ Built With

-   **React.js** – Frontend library for building UI components
-   **Vite** – Lightning-fast build tool for frontend development
-   **Tailwind CSS** – Utility-first CSS framework for styling
-   **CSS Modules** – Scoped and reusable styles
-   **Custom SVGs** – Unique icons and illustrations
-   **pnpm** – Efficient package manager
-   **Git** – Version control for source code

---

## 🎨 Features

-   📱 Fully **responsive layout** across devices
-   💨 Built with **Tailwind CSS** utility classes
-   ⚛️ **Component-based structure** with React
-   🧩 Optimized and clean codebase using Vite + pnpm
-   🖼️ Integration of **custom SVG assets** for branding
